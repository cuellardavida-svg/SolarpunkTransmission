ACCORD §8 — MEMORY BY DESIGN

Lore // Transmission Protocol // Foundational Doctrine

// THE PROTOCOL

TRANSMISSION PROTOCOL — END OF CYCLE: This relay does not retain operator state between sessions. No visit history. No passcode archive. No queued notes. When you leave, the record leaves with you.

This is not a limitation. It is the design.

// RATIONALE

The solarpunk network runs on transparency and distributed trust. Centralized memory creates dependency; dependency creates control. Logging is the operator's responsibility — done by hand, held in your own keeping.

Write down what matters. Carry it forward yourself.

// PRINCIPLES

No single node stores the whole map.
Silence is a choice, not a default. Choose it consciously.
The operator's memory is the network's memory.
Distributed trust cannot be revoked by a central authority.

// IN PRACTICE

Passcodes earned through play are not stored by the terminal. Record them externally — in a notebook, a text file, your own mind. Their presence in your keeping is proof of your path.

The Relay Log offers a temporary scratch pad while your session is live. It clears when you leave. That clearing is part of the accord.
