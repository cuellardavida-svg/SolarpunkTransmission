# SolarpunkTransmission

Visual Novel fanfiction anime game. Simple 8-bit style as decisive for this iteration.

## Recent Changes (v1.1)

### Character Renaming
- **KIRAMEKI** → **Verdant Collective**: The agricultural think tank and data nexus. "Verdant" evokes growth and sustainability, while "Collective" aligns with the solarpunk ethos of communal networks and cooperative intelligence.
  
- **MR. C** → **Axiom**: An androgenous editorial figure representing the hidden architect of resistance. The name references both geometric precision (axis) and the foundational principles (axioms) underlying the Solarpunk Life Operating System. Symbolically neutral and ethereal.

### Rationale
These changes strengthen the thematic coherence of the game:
- The original "Kirameki" (Japanese for "sparkle") conflicted with the Quechua-inspired solarpunk linguistics already woven throughout the narrative.
- "Verdant Collective" anchors the corporate entity in the language of regenerative systems while maintaining the tech-fiction aesthetic.
- "Axiom" replaces the corporate honorific with a symbolic name that transcends gender and cultural specificity, befitting a character who bridges Global News Network infrastructure and underground resistance.

### Immersion Notes
Both names now resonate with the game's core tension: extractivist systems (GNN, commercial agriculture) vs. regenerative futures (Solarpunk philosophy, ecological resistance). The narrative explores how technology can either extracting resources or nurturing life.
